Build the ATS Intelligence Ingestion Layer for the Recruiting Intelligence Framework.

IMPORTANT:
The framework is NOT:
- an ATS
- a recruiting CRM
- a workflow replacement system

The framework IS:
- a provenance-first recruiting intelligence layer
- a replayable organizational reasoning system
- an audit-grade cognition infrastructure

The ATS strategy is now explicit:

ATS systems are:
- the operational system of record
- the source of hiring evidence
- the source of organizational reasoning traces

The framework reconstructs:
- hiring cognition
- disagreement
- escalation
- calibration
- overrides
- organizational reasoning lineage

--------------------------------------------------
Core Thesis
--------------------------------------------------

Organizations already store:
- scorecards
- interview notes
- hiring decisions
- reviewer comments
- overrides
- escalation rationale

inside ATS systems.

But almost no system can:
- replay how the organization reasoned,
- inspect disagreement,
- audit confidence,
- analyze calibration,
- reconstruct hiring cognition over time.

This layer bridges:
ATS operational evidence
→ recruiting intelligence replay.

--------------------------------------------------
4. ATSNormalizationEngine
--------------------------------------------------

Normalize ATS operational evidence.

Convert ATS artifacts into:
- explicit_claim
- reviewer_assessment
- contradiction_signal
- uncertainty_signal
- escalation_signal
- override_signal
- calibration_signal

Every normalized evidence item must include:
- source ATS
- ATS object id
- reviewer identity
- ingestion timestamp
- original payload hash
- provenance chain

IMPORTANT:
Do NOT flatten disagreement.
Preserve reviewer separation.
