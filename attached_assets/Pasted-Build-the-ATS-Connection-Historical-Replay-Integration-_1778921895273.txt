Build the ATS Connection & Historical Replay Integration Layer for the Recruiting Intelligence Framework.

IMPORTANT:
The framework is NOT:
- an ATS
- a workflow engine
- a recruiting CRM
- a stage automation system

The framework IS:
- a replayable recruiting intelligence layer
- an organizational reasoning reconstruction system
- a provenance-first cognition infrastructure
- an audit-grade hiring replay platform

The ATS is:
- the operational source of truth
- the source of evidence
- the source of reviewer reasoning traces

The framework reconstructs:
- disagreement
- escalation
- confidence evolution
- calibration
- overrides
- organizational reasoning

--------------------------------------------------
Core Goal
--------------------------------------------------

Enable organizations to:

Connect their ATS
→ ingest historical hiring evidence
→ replay real hiring decisions
→ inspect disagreement
→ inspect calibration
→ inspect overrides
→ inspect reasoning evolution

The emotional outcome should be:

"We have never been able to replay how we reasoned about hiring before."

- Ashby
