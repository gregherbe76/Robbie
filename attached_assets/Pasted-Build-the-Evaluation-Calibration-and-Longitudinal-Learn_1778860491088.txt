Build the Evaluation, Calibration, and Longitudinal Learning Layer for the Recruiting Intelligence Framework.

IMPORTANT:
The framework now has:
- candidate intelligence
- cross-agent cognition
- organization intelligence
- deterministic orchestration
- provenance-first reasoning
- auditability

The next step is NOT more agents.

The next step is:
- measuring predictive quality,
- calibrating reasoning,
- learning from outcomes,
- longitudinal intelligence evolution.

The system must evolve from:
"reasoning system"

into:
"self-calibrating recruiting cognition system."

--------------------------------------------------
Core Thesis
--------------------------------------------------

A recruiting intelligence system must:
- remember outcomes,
- compare predictions to reality,
- detect calibration drift,
- refine confidence over time,
- measure reasoning quality,
- track archetype success/failure longitudinally.

This layer introduces:
- evaluation,
- calibration,
- feedback loops,
- longitudinal organizational learning.

- per-agent calibration
- global calibration
- organization-specific calibration
- archetype-specific calibration
